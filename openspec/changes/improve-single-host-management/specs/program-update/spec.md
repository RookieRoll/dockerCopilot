# Spec Delta

## Purpose

规范 dockerCopilot 自身版本查询和在线升级，使同一仓库的版本、资产和实际运行程序保持一致，在网络、下载或安装失败时保留当前可用程序，并提供可定位的任务和日志结果。

## ADDED Requirements

### Requirement: 自身更新源一致
版本检查和升级资产 SHALL 使用同一配置的仓库与发布通道，默认 RookieRoll/dockerCopilot 的 latest/version 及对应版本 release，保留 githubProxy 支持。更改更新源 MUST NOT 要求更改 Go 模块导入路径。

#### Scenario: 使用默认仓库检查并升级
- **WHEN** 用户查询远端版本并随后执行在线升级
- **THEN** 版本文件与下载资产均来自 RookieRoll/dockerCopilot 的对应配置，代理前缀按同一规则处理

### Requirement: 远端响应验证与真实错误返回
版本查询 MUST 验证 HTTP 状态、响应大小及版本格式，设置有限超时，失败时不得更新成功缓存或返回成功。网络和解析错误 SHALL 生成合法错误响应与可关联日志，不能触发 HTTP 状态码 panic。

#### Scenario: 版本地址返回 404 页面
- **WHEN** 远端版本请求返回非成功状态或 HTML 错误页
- **THEN** 报告查询失败，不将页面正文缓存为版本号或构造升级下载地址

#### Scenario: 查询超时
- **WHEN** 版本查询达到期限
- **THEN** 返回明确超时错误及诊断标识，不安排程序退出

### Requirement: 升级资产校验后才可安装
升级 SHALL 下载与当前架构匹配的资产到隔离暂存位置，验证 HTTP 状态、大小、SHA256 和预期文件布局。缺失校验文件、不匹配、非法路径或链接 SHALL 拒绝安装，当前程序保持运行。

#### Scenario: 校验值不匹配
- **WHEN** 下载包与发布校验值不同
- **THEN** 任务失败，不替换当前程序、不请求重启，并保留可诊断原因

#### Scenario: 旧 release 没有校验文件
- **WHEN** 目标版本不提供新升级器要求的校验文件
- **THEN** 返回明确的不支持在线安装结果，当前程序继续运行

#### Scenario: 归档包含越界路径
- **WHEN** 包内包含路径穿越、链接或非预期安装文件
- **THEN** 拒绝安装，工作目录外文件和现有程序不被覆盖

### Requirement: 发布包与安装入口一致
发布构建 SHALL 为 Linux amd64 和 arm64 提供可验证的升级资产及校验文件，解包结果 MUST 与启动安装入口一致，并包含完整嵌入式前端。构建或包验证失败 MUST 阻止发布不可用资产。

#### Scenario: 安装任一支持架构的包
- **WHEN** 对应架构升级包通过校验并进入安装
- **THEN** 启动入口能定位预期新程序，不因 dist/linux 子目录差异而继续运行旧文件

### Requirement: 自身升级与活动操作协调
系统 SHALL 同时最多执行一个自身升级任务；安装交接前 MUST 排空其他修改任务并暂停接受新修改。排空超时、重启前提不可确认或安装目录不可写时 SHALL 失败并恢复正常接受，不退出当前程序。

#### Scenario: 容器更新尚未结束
- **WHEN** 自身升级准备完毕而容器更新仍在进行
- **THEN** 等待有界排空，不能直接退出打断容器更新；超限时本次自身升级失败

#### Scenario: 只读安装目录
- **WHEN** 程序工作目录不可写
- **THEN** 在线升级在安装交接前失败，页面解释部署前提，当前服务继续运行

### Requirement: 安装交接与实际版本确认
系统 SHALL 保存待安装目标和任务关联，保留旧程序供人工恢复。下载或解压完成不得直接标记升级成功；新进程 SHALL 根据目标版本和服务就绪状态确认结果。缺失、失败或无法确认的交接 MUST 明确显示中断或失败，不无限等待或声称已升级。

#### Scenario: 新程序启动并就绪
- **WHEN** 新进程的运行版本等于待安装目标且管理服务已就绪
- **THEN** 对应升级任务标记成功，页面重连后可确认实际版本

#### Scenario: 重启后仍是旧版本
- **WHEN** 重启后的运行版本与待安装目标不符
- **THEN** 升级任务报告失败或中断并记录运行与目标版本，保留旧程序和人工恢复信息

#### Scenario: 新程序无法启动
- **WHEN** 安装后新程序无法提供管理服务
- **THEN** 已落盘的安装记录与启动日志能够用于定位，旧程序保留可供人工恢复，系统不承诺自动回退
