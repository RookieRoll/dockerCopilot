# Spec Delta

## Purpose

为容器更新、恢复、批量修改、备份导出和自身升级提供一致的后台任务语义，使用户在页面刷新、短暂断网或服务重启后仍可查询操作事实，并区分接受、执行和最终结果。

## ADDED Requirements

### Requirement: 任务接受具有可查询记录
系统 MUST 在接受长任务前保存可查询记录并分配唯一任务 ID；接受响应 SHALL 表达已接受而不是已完成。记录无法保存或队列已满时 MUST 拒绝接受且不执行任务。所有任务入口和查询 MUST 保持认证要求。

#### Scenario: 正常接受任务
- **WHEN** 已认证用户提交合法长任务且执行容量允许
- **THEN** 返回任务 ID，立即查询可以得到 queued 或 running 状态

#### Scenario: 状态目录无法写入
- **WHEN** 系统无法保存初始任务记录
- **THEN** 返回明确错误，不执行 Docker 修改或文件导出

### Requirement: 任务结果结构稳定
任务 SHALL 返回 status、stage、时间、对象标识、错误、恢复结果、警告及适用的逐项结果；status SHALL 为 queued/running/succeeded/failed/interrupted 之一。保留 progress 旧字段时，isDone MUST 与终态一致；完成状态 MUST NOT 被后续进度覆盖。

#### Scenario: 查询已失败任务
- **WHEN** 用户成功查询一个失败任务
- **THEN** 查询 HTTP 状态为 200，任务 status 为 failed，包含失败阶段及原因，isDone 为 true

#### Scenario: 延迟进度到达
- **WHEN** 任务已经结束后出现旧的下载进度通知
- **THEN** 任务终态和最终结果不被改回执行中

### Requirement: 有界执行与异常收尾
任务执行 SHALL 受配置的队列容量、并发和期限约束；请求连接断开 MUST NOT 自动取消已接受任务。正常错误、panic、超时和部分失败 MUST 形成明确结果。总期限到达后的必要恢复 SHALL 使用独立且有界的时间预算。

#### Scenario: 浏览器在更新期间断开
- **WHEN** 提交成功后浏览器连接断开
- **THEN** 后端继续执行该任务，重连后可查询同一 ID

#### Scenario: 后台任务发生 panic
- **WHEN** 任务执行产生可捕获 panic
- **THEN** 记录异常及任务标识，标记失败或结果不确定，释放可释放的操作占用，不能永远保持 running

#### Scenario: 超时后恢复旧容器
- **WHEN** 更新期限到达且旧容器已停止
- **THEN** 在独立恢复预算内尝试安全恢复，记录恢复结果，不无限等待

### Requirement: 服务重启保留任务事实
系统 SHALL 持久保存关键阶段和最终结果。重启后普通未完成任务 MUST 标记 interrupted，保留关联对象并只读核对其现状；不得自动重放替换、删除等破坏性动作。具有完整安装交接记录的自身升级任务 SHALL 按 program-update 的版本确认规则收尾。损坏记录 MUST 被保留并告警，不能被解释为任务成功。

#### Scenario: 替换过程中服务重启
- **WHEN** 上次记录显示旧容器已改名而任务尚未结束
- **THEN** 重启后任务显示中断、原名称和相关 ID、当前可获取的容器状态及人工处理提示

#### Scenario: 个别记录损坏
- **WHEN** 一个任务文件无法解析
- **THEN** 系统保留该文件供排查、记录警告，其他有效任务仍可查询

### Requirement: 页面恢复任务与准确反馈
页面 SHALL 通过已知任务 ID 或按容器查询任务恢复操作状态，支持刷新及网络故障后继续查询。查询失败 SHALL 表达连接或查询问题，不能推断任务失败；终态 SHALL 触发相关页面数据刷新，并展示错误或清理警告。

#### Scenario: 更新 Tailscale 导致临时失联
- **WHEN** 已接受任务期间进度查询暂时不可达
- **THEN** 页面显示连接中断、任务结果待确认，退避重试，恢复后展示服务端实际结果

#### Scenario: 长任务超过两分钟
- **WHEN** 后端任务仍在执行且尚未达到服务端期限
- **THEN** 页面继续查询，不因固定轮询次数耗尽而将任务当作失败

### Requirement: 任务记录保留与信息保护
任务记录 SHALL 有可配置保留期和数量上限；活动任务以及仍保护配置或需要人工处理的记录不得按普通历史策略清理。公共查询 MUST NOT 返回容器环境变量、完整配置快照或凭据；返回结果 SHALL 支持有限分页。单实例状态目录 MUST 拒绝并发写入实例。

#### Scenario: 过期任务清理
- **WHEN** 已结束记录超过保留策略而另有运行中任务
- **THEN** 清理符合条件的已结束记录，运行中任务仍可查询

#### Scenario: 第二个实例使用同一状态目录
- **WHEN** 状态目录已被运行实例独占
- **THEN** 第二个写入实例启动失败并给出明确原因，不覆盖任务文件

#### Scenario: 中断任务仍保护端口配置
- **WHEN** 一个中断任务超过普通保留期但仍含未解决的容器恢复或配置保护信息
- **THEN** 记录与必要快照继续保留并标记需要处理，核对确认稳定或人工处理后才解除保留
