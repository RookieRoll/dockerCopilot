# 页面兼容边界

2026-10-23 按用户要求，单主机架构升级仅优化后端，撤回升级过程中新增的页面内容。页面布局和既有操作入口以架构升级前提交 `d64169d` 为基准；容器更新保留原有行内进度，不增加独立任务列表、任务状态面板、任务/请求 ID 复制入口、批量汇总区、镜像检查状态区或程序升级与人工恢复区块。

后端保留有限并发、进程内进度、操作协调、更新验证与即时恢复、业务配置原子写入、镜像保护和日志记录。普通操作进度不跨服务重启保存。前端仅保留与这些后端能力兼容所需的内部处理：任务接受后的查询、刷新续查、断线重试、终态确认及缓存刷新。请求被接受不表示操作成功，查询断网不表示后台失败，也不会自动重放修改请求；结果通过原有行内状态、加载状态及成功/失败反馈展示。

详细任务、逐项结果、恢复说明、警告以及任务/请求 ID 由已认证 API 和服务日志提供，排障入口见[后台任务排障](task-troubleshooting.md)。不新增可见页面来暴露后端内部机制。

本次边界覆盖先前架构方案中要求增加任务面板等 UI 的部分。原方案、首轮验收记录及旧截图保留为历史实施证据，不代表当前界面；后端相关设计与验收结论仍然有效。

| 场景 | 结果 |
