# 进程内操作进度

`internal/task` 只保存当前服务进程的操作进度和私有恢复快照，不创建任务目录、JSON 记录、锁文件或损坏隔离目录。服务启动不扫描旧任务，也不自动重放操作。原有配置备份、端口配置和日志文件继续按各自业务规则保存。

记录默认最多 1000 条、每条最多 1 MiB、合计最多 32 MiB；私有快照每份最多 8 MiB、合计最多 32 MiB。已完成且没有未决恢复事项的普通记录保留 10 分钟，访问或写入时按需清理。活动操作和需要核对的恢复事实不能为了腾出容量而删除，容量耗尽时拒绝新操作。

快照首次写入后不可覆盖，公共 API 不暴露快照内容。检查点只保证当前进程内状态一致，不能保证断电或重启后恢复。进程退出后普通操作的结果需要结合 Docker 当前状态与日志判断。

旧 `Tasks.Directory`、`QueueCapacity`、`Retention`、`MaxRecords` 配置仅兼容读取，不再控制运行行为。详细行为见 [执行器](task-runner.md) 和 [进度查询](task-query-recovery.md)。
