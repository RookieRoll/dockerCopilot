# 后台操作执行器

`internal/task` 提供有限并发的进程内执行器，默认并发 2、操作期限 30 分钟、即时恢复期限 2 分钟。没有等待队列；容量已满时拒绝新操作。接受响应只表示已登记并开始后台处理，不能当作完成。

操作上下文独立于 HTTP 请求，浏览器断线不会取消已接受的操作。修改 Docker 前通过 `Execution.Critical` 更新当前进程的恢复事实；更新成功后通过提交检查点固定替换结果，后续清理错误不能回滚已验证的新实例。

超时会取消操作上下文。Go 无法强杀忽略取消的函数，因此原回调未退出前保留运行状态、并发额度和容器占用，并提示等待核对。原回调退出后才运行即时恢复，恢复使用独立期限；恢复真实退出后再确定终态并释放占用，避免恢复与原操作并行修改 Docker。已提交的新实例不会因为清理超时而回滚。

`Close` 停止接收并取消活动操作，等待回调退出。回调必须遵守 context，不得遗留继续修改 Docker 的后台 goroutine。批量操作在同一个并发额度内串行处理项目，不递归提交子任务。

日志记录请求 ID、操作 ID、阶段、目标、耗时、错误和恢复结果；进度和恢复快照不落任务文件。程序自身升级所需的 launcher 交接文件由专用流程管理，见 [程序升级](program-update.md)。
