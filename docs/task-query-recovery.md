# 进度查询与结果核对

`GET /api/progress/:taskid` 保留原有进度字段，公共投影排除私有配置快照。`GET /api/tasks` 仅作为现有客户端查找当前进程操作的兼容接口，支持原有过滤与分页，不提供持久历史或重启续跑。

普通操作记录在服务重启或保留期结束后不可查询。进度接口返回 HTTP 410、`errorCode: OPERATION_RESULT_EXPIRED`，提示“操作结果未知，请核对容器状态和日志”。客户端停止查询该旧进度，不自动重放修改请求。连接错误仍按退避策略重试，不能将断线判断成操作失败。

进程仍存活时，更新失败会在原操作回调退出后尝试即时恢复；恢复失败或对象归属不明时保留当前进程的保护信息，提示人工核对。服务崩溃后的核对由管理员结合 Docker 状态、时间及日志完成，没有启动扫描或通用任务恢复器。

程序自身升级是必要例外：launcher 的专用交接标记与结果仍保存到程序目录，新进程核验运行二进制和 HTTP 就绪后可重建本次升级结果；这不恢复普通容器操作。
